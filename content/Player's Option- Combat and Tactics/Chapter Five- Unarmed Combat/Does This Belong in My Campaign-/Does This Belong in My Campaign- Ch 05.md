Does This Belong in My Campaign? The material in this chapter is an extension of the combat options in [[Player's Option- Combat and Tactics/Chapter Two- Combat Options/Combat Options|Chapter Two]], and it is intended for use with the *Player’s Option* combat system presented in [[Player's Option- Combat and Tactics/Chapter One- Player's Option Combat System/Player's Option Combat System|Chapter One]]. This chapter can be used by itself, however.

Brawling, subduing, and martial arts can all be incorporated into a campaign separately or together.
