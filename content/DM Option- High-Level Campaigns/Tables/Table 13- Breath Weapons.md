Breath Weapons

|  |  |  |
| --- | --- | --- |
| **Rank** | **Damage**1** | **Save Mod.

**2** |
| Lesser Scion | 26–35 | –2 |
| Scion | 36–45 | –3 |
| Elder | 46–55 | –4 |
| Great Elder | 56–65 | –5 |
| Paragon | 66–75 | –6 |

1 The numbers indicate the average damage inflicted. Any number of dice or combination of dice and a modifier that produces an average that falls within the listed range is acceptable. For example, a scion might have a breath weapon that inflicts 10d8 points of damage (average 45) or 10d6+10 points of damage. See below for average results from commonly used dice.

2 *Saving Throw Modifier:* This is used *only* for breath weapons that do not inflict damage. For example, a gorgon’s petrifying breath.

Breath Weapon Sizes

|  |  |  |  |
| --- | --- | --- | --- |
| **Rank** | **Cloud** | **Cone** | **Line** |
| Lesser Scion | 30' | 40' | 60' |
| Scion | 40' | 55' | 80' |
| Elder | 50' | 70' | 100' |
| Great Elder | 60' | 85' | 120' |
| Paragon | 70' | 100' | 140' |

*Cloud:* The effect is 50' wide, 40' tall, and 30–70' long.

*Cone:* The effect is 5' in diameter at the creature’s mouth, 30' in diameter at its apex, and 40–100' long.

*Line:* The effect is 5' wide, 5' tall, and from 60–140' long.
