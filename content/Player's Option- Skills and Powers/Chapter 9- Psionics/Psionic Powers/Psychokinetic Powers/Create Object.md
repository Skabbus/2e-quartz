Create Object**

(psychokinetic science)**

|  |  |
| --- | --- |
| MAC: | 6 |
| PSP Cost: | 7/3 |
| Range: | 20 yards |
| Area of Effect: | Special |
| Prerequisite: | Telekinesis |

This power allows a user to assemble matter from air and the surrounding area to create a solid object. Only materials within 20 yards of the user can be used in the construction. The object remains in existence for every round that the user continues to pay the PSP cost. During the round that the PSP cost isn’t paid, the object breaks apart. An object created with this power can have any shape, color, and texture the user desires, provided it fulfills at least one of these conditions:· Fits within a sphere no more than 4 feet in diameter.· Fits within a cylinder no more than 20 feet high and 1 foot in diameter.· Fits within a cylinder no more than 2 feet high and 6 feet in diameter.· Weighs no more than 10 pounds.
