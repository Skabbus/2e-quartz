GemsWhen gems are found, determine the value of each gem (or each group of gems if there are many present) on [[Dungeon Master Guide/Tables/Table 85- Gem Table|Table 85]] . This table lists the base value for each gem and the general class of each stone for purposes of description. Uncut stones, if found, have their base value reduced to 10% of the amount listed.

In addition, there is a 10% chance that any given stone will be above or below its normal value. (Assume 10% of the stones present in a large horde are automatically unusual.) These gems can be modified according to [[Dungeon Master Guide/Tables/Table 86- Gem Variations|Table 86]] .Although you can choose to describe gems solely by their values ("You found a 50 gp gem"), more flavor is gained by described stones by name and color.
