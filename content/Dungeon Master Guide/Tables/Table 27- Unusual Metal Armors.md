**Table 27:**

**Unusual Metal Armors**

|  |  |  |  |
| --- | --- | --- | --- |
| **Metal** | **AC Adjustment** | **Weight Adj.** | **Cost Multiplier** |
| Adamantite | +1 | -25% | x500 |
| Bronze | -1 | 0 | x2/3 |
| Elven Steel | 0 | -50% | \*\* |
| Fine Steel | 0 | -10% | x2 |
| Gold | -4 | +100% | x3\* |
| Iron | 0 | +25% | 0 |
| Silver | -2 | 0 | x2\* |

The *AC adjustment* in no way implies that the armor has magical properties, only that the material is better or worse than normal. Thus, no bonuses are gained for saving throws, etc.\* The character must provide the amount of metal needed to make the suit (determined by weight). In addition, the character must multiply the normal cost of the armor by the multiplier listed and pay this as fabrication cost.\*\* Elven armors can't normally be purchased, being given as gifts to those the elves deem worthy.
