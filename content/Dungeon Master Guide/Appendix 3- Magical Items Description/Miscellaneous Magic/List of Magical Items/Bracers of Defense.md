**Bracers of Defense**

:** These items appear to be wrist or arm guards. Their magic bestows an effective Armor Class equal to someone wearing armor and employing a shield. If armor is actually worn, the bracers have no additional effect, but they do work in conjunction with other magical items of protection. The Armor Class the *bracers of defense* bestow is determined by making a percentile roll and consulting the table below:

|  |  |
| --- | --- |
| **D100 Roll** | **Armor Class** |
| 01-05 | 8 |
| 06-15 | 7 |
| 16-35 | 6 |
| 36-50 | 5 |
| 51-70 | 4 |
| 71-85 | 3 |
| 86-00 | 2 |
