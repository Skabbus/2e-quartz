**Sword +2, Dragon Slayer**

:** This has a +4 bonus against any sort of true dragon. It inflicts triple damage against one sort of dragon (i.e., 3d12+4). Note that an unusual sword with intelligence and alignment will not be made to slay dragons of the same alignment. Determine dragon type (excluding unique ones like Bahamut and Tiamat) by rolling 1d10:

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
|  | 1 | black (CE) | 6 | gold (LG) |
|  | 2 | blue (LE) | 7 | green (LE) |
|  | 3 | brass (CG) | 8 | red (CE) |
|  | 4 | bronze (LG) | 9 | silver (LG) |
|  | 5 | copper (CG) | 10 | white (CE) |
