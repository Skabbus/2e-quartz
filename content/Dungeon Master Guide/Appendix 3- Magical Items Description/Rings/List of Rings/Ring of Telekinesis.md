**Ring of Telekinesis**

:** This ring enables the wearer to manipulate objects in the same manner as the 5th-level wizard spell, *telekinesis.* The amount of weight the wearer can move varies. Roll percentile dice to find the strength of the ring:

|  |  |  |
| --- | --- | --- |
|  | 01-25 | 25 lbs. maximum |
|  | 26-50 | 50 lbs. maximum |
|  | 51-89 | 100 lbs. maximum |
|  | 90-99 | 200 lbs. maximum |
|  | 00 | 400 lbs. maximum |
