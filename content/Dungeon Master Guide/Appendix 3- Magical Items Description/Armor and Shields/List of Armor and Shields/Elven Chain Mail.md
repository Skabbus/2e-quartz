**Elven Chain Mail**

:** This is magical armor so fine and light that it can be worn under normal clothing without revealing its presence. Its lightness and flexibility allow even bards and thieves to use it with few restrictions (see [Chapter 3](..\PHB\DD01456.htm) in the *PHB*). Elven fighter/mages use it without restriction. However, it is rarely sized to fit anyone other than an elf or a half-elf. Roll percentile dice and consult the following table to ascertain what size character *elven chain mail* will fit:

|  |  |
| --- | --- |
| **D100 Roll** | **Size of Elven Chain Mail** |
| 01-10 | gnome/halfling (hairfoot) |
| 11-15 | dwarf/halfling (Stout or Tallfellow) |
| 16-80 | elf/half-elf |
| 81-95 | man-sized, normal (up to 6 feet, 200 lbs.) |
| 96-00 | man-sized, large (up to 6½ feet, 250 lbs.) |
