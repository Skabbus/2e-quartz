Step Three: Ground Cover and WaterNow, take each section of the map and determine how dense the ground cover is in that area. The categories are clear (C), thickets or brambles (T), light woods (L), and heavy woods (H). Roll a d6 for each area and consult the chart below:

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
|  | **1** | **2** | **3** | **4** | **5** | **6** |
| Light Woods | C | C | T | L | L | H |
| Heavy Woods | C | T | L | H | H | H |
| Swamp | C | C | T | T | L | L |
| Hills | C | C | C | C | T | L |
| Plains | C | C | C | C | C | T |
