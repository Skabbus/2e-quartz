## Alertness

(Proficiency)

|  |  |
| --- | --- |
| Name | Alertness |
| Crossover Group | General |
| Relevant Ability | Wisdom |
| Check Modifier | +1 |
| # of Slots | 1 Slot |

A character with this proficiency has an instinctive knack for noticing disturbances and discrepancies in the immediate vicinity. A successful proficiency check reduces the character's chance of being surprised by 1. (This replaces the description of the alertness proficiency in [[00_Rulebook/The Complete Thief's Handbook/Chapter 2- Proficiencies/New Proficiencies/Alertness|*The Complete Thief's Handbook*]].)

**Crossover Group:** General.
