**Table 23:**

Risk of Insanity by Spell Level

|  |  |  |
| --- | --- | --- |
| **Spell** | **Chance of** | **Modifier to Random** |
| **Level** | **Insanity**1 | **Insanity Chart Roll** |
| 1st | 4% | none |
| 2nd | 6% | none |
| 3rd | 10% | +5% |
| 4th | 15% | +10% |
| 5th | 22% | +15% |
| 6th | 30% | +20% |
| 7th | 40% | +25% |
| 8th | 50% | +30% |
| 9th | 60%2 | +40% |

1 Increase the chance of insanity by one level if the wizard succeeds in his learn spells roll; for example, if a character learns a 3rd-level spell, his insanity chance is actually 15%. The modifier to the insanity chart is still based on the spell’s actual level.

2 Maximum chance of insanity
