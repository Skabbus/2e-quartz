## Eating

(Proficiency)

|  |  |
| --- | --- |
| Name | Eating |
| Group(s) | General |
| Ability | Constitution |
| Modifier | 0 |
| Slots | 1 |

Much like the drinking proficiency, this proficiency allows the humanoid to store up food. A successful check indicates that the humanoid can consume up to twice as much as normal. This allows the humanoid to go twice as long without food without suffering any adverse effects from hunger.
