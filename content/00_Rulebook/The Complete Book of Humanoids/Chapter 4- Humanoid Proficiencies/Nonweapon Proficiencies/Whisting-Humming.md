## Whistling / Humming (Proficiency)

|  |  |
| --- | --- |
| Name | Whistling/Humming |
| Group(s) | General |
| Ability | Dexterity |
| Modifier | +2 |
| Slots | 1 |

Characters with this proficiency are exceptional whistlers and hummers. They can produce tunes as captivating as most songs. If a successful check is made, the character knows any particular tune in question. If he also has the animal lore proficiency, he can mimic any bird call he has ever heard.

Adventurers also use this proficiency to communicate with each other. This type of communication is only possible among the characters whd have this proficiency. If two or more characters with this proficiency make successful checks, a single concept can be communicated between them.
