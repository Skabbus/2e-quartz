## Hiding

(Proficiency)

|  |  |
| --- | --- |
| Name | Hiding |
| Group(s) | General |
| Ability | Intelligence |
| Modifier | -1 |
| Slots | 2 Slots |

Hiding is the ability to instinctively select the best hiding place under nearly any condition. Humanoids who make successful checks can virtually disappear from view. Success is determined by modifiers based upon the Intelligence of the character being hidden from. This proficiency operates independently of any natural camouflage or hiding ability the humanoid might already have.

Hiding Modifiers

| Opponent's Intelligence | Modifier |
| --- | --- |
| 3 or less | -5 |
| 4-5 | -3 |
| 6-8 | -1 |
| 9-12 | 0 |
| 13-15 | +1 |
| 16-17 | +2 |
| 18 | +3 |
| 19 | +5 |
| 20+ | +7 |
