**Ring of Protection**

:** A *ring of protection* improves the wearer's Armor Class value and saving throws versus all forms of attack. A *ring +1* betters AC by 1 (say, from 10 to 9) and gives a bonus of +1 on saving throw die rolls. The magical properties of a *ring of protection* are cumulative with all other magical items of protection except as follows:1. The ring does not improve Armor Class if magical armor is worn, although it does add to saving throw die rolls.2. Multiple *rings of protection* operating on the same person, or in the same area, do not combine protection. To determine the value of a *protection ring,* use the following table:

|  |  |
| --- | --- |
| **D100** |  |
| **Roll** | **Level of Protection** |
| 01-70 | +1 |
| 71-82 | +2 |
| 83 | +2, 5-foot radius protection |
| 84-90 | +3 |
| 91 | +3, 5-foot radius protection |
| 92-97 | +4 on AC, +2 to saving throws |
| 98-00 | +6 on AC, +1 to saving throws |

The radius bonus of 5 feet extends to all creatures within its circle, but applies only to their saving throws (i.e., only the ring wearer gains Armor Class additions).
