**Basic Spells**A new school does not need an extensive number of spells immediately. Beginning with a core of basic spells is best, adding new spells as required by the campaign and the players.

An acceptable core of basic spells includes the number of spells for each level given in Table 1. Note that this is approximately the number of spells for the schools of greater divination and necromancy given in the *Player's Handbook*. If the DM is unable to invent this number of spells, he should concentrate on designing spells to fill the lower levels (levels 1-3) so his lower-level specialists can begin their careers**Table 1: Minimum Spells for A New School**

|  |  |
| --- | --- |
| **Level** | **No. of Spells** |
| 1st | 3 |
| 2nd | 3 |
| 3rd | 2 |
| 4th | 2 |
| 5th | 2 |
| 6th | 2 |
| 7th | 1 |
| 8th | 1 |
| 9th | 1 |
