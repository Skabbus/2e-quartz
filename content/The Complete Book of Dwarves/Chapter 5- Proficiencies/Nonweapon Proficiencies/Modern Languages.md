## Modern Languages

(Proficiency)

|  |  |
| --- | --- |
| Name | Modern Languages |
| Crossover Group | General |
| Relevant Ability | Intelligence |
| Check Modifier | 0 |
| # of Slots | 1 |

The modern languages dwarves may learn are determined by the campaign background. If a character lives in a stronghold that has had no contact with goblins, he is unlikely to have learned goblin. The languages for dwarves in the [Player's Handbook](..\PHB\DD01445.htm) should be considered as suggestions only. Dwarves may learn any language that suits their background. Suggested languages are: deep tongue, drow, elf, gnome, goblin, local human common tongue, kobold, orc, troll, ogre.
